# 命名与目录约定（脱敏版）

## 命名公式

本地/官网库用占位符命名，出现姓名、学校、专业时替换为真实信息：

| 场景 | 中文 | 英文 |
|---|---|---|
| 广告方向 | `A-姓名-学校-专业` | `A-Name-School-Program` |
| 公关方向 | `P-姓名-学校-专业` | `P-Name-School-Program` |

示例（占位）：

- `A-张三-示例大学-传播学硕士.pdf`
- `P-ZhangSan-ExampleUni-MA-Communication.pdf`

投递时按招聘方要求或区域公式临时重命名：

- 香港/外资：`Name_PR_Communications.pdf`（英文全名 + 职位）；
- 内地：`姓名-岗位-核心优势.pdf`；
- 招聘方有明确格式要求时，以招聘方为准，高于一切公式。

规则：分隔符用 `-` 或 `_`，不加空格；避免特殊符号；文件被下载后脱离文件夹也能看懂方向。

## 目录职责

| 目录 | 职责 |
|---|---|
| `MD和PDF/` | Markdown 是现行内容源；旧版 PDF 必须重命名加 `-旧版` 标注，不得当作投递件 |
| `Latex渲染版-终PDF/` | 最终交付 PDF，按方向分子目录 |
| `Latex渲染版-终PDF/_LaTeX源文件/` | 可编辑 tex 源文件（与终 PDF 同名） |
| `备份-YYYY-MM-DD/` | 改动前快照；命名保持改动前旧名，用于回退 |
| `Latex模板/` | 脱敏模板、字体、照片、skill |

## 改动规范

- 重写可能被其他文件引用的文档前，先把旧文件复制到带日期的备份目录；
- 改名要做全局统一（MD、tex、PDF 一套基名，只换扩展名）；
- 模板和最终产出的版式、照片规则必须保持一致；英文模板/产出不放照片。

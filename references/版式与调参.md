# 版式参数与调参

## 模板参数总表（当前基线）

| 项目 | A-广告-中文 | P-公关-中文 | A-广告-英文 | P-公关-英文 |
|---|---|---|---|---|
| 页面目标 | 1 页 | 1 页 | 2 页 | 2 页 |
| 正文字号 | 10pt | 9pt | 11pt | 11pt |
| 行距（linespread） | 1.02 | 1.02 | 1.06 | 1.02 |
| 页边距 | 1.27cm | 1.27cm | 1.27cm | 1.27cm |
| 姓名 | 20pt | 20pt | 22pt | 22pt |
| 联系方式 | 10pt | 10pt | 11pt | 11pt |
| 节标题 | 13pt | 13pt | 13pt | 13pt |
| 照片 | 一寸照 2.2cm | 一寸照 1.9cm | 无 | 无 |
| 条目间距 | 2.5pt | 1.5pt | 7pt | 3pt |
| 行后距（cventry/cvline） | 0.2pt | 0.2pt | 0.5pt | 0.5pt |
| 节前距 / 节后距 | 5pt / 2pt | 5pt / 2pt | 10pt / 3pt | 5pt / 1pt |

> 参数以 `assets/templates/` 内实际 tex 为准；上表是当前迭代基线，改动后应回写。

## 调参阶梯（只动版式，不动内容）

按顺序尝试，每步编译验证：

1. 页边距（1.27cm 是约定红线，一般不先动）；
2. 节前距 / 节后距；
3. 条目间距（条目之间的 `\vspace`）；
4. 行后距（cventry/cvline 的 `\vspace`）；
5. 行距 `\linespread`；
6. 正文字号（中文广告 10pt / 公关 9pt、英文 11pt 是基线，尽量不动）；
7. 照片宽度（中文版，约 1.9–2.2cm 可调）。

英文版内容多，调参时要区分两套参数：广告版较宽松（条目 7pt、节前 10pt），公关版必须更紧（条目 3pt、节前 5pt），否则会从 2 页变 3 页。

## “一页差一行”处理

- 先看底部余量：`pdftotext -bbox` 取最大 yMax，页面可用下限约 805.7pt（A4 − 1.27cm 上下边距）。
- 中文广告版常见余量约 10pt、公关版约 5pt；英文公关版第二页余量约 40pt。
- 差一行时优先：列表缩进 `leftmargin` 1.1em → 1.0em（减少换行）→ 行后距 −0.1pt → 条目间距 −0.5pt。
- 调到极限仍差：停下来向用户说明，给出“接受多一页 / 允许更小幅号或更紧边距 / 内容取舍”三个选项，不擅自删内容。

## 阅读体验优先的做法

- 把空间优先给行距，而不是条目间距（行距对阅读影响最大）。
- 加 `\setlength{\emergencystretch}{1.5em}` 减少两端对齐的大空隙。
- 英文断页必须干净：widow/club penalty + 条目标题后 `\nopagebreak`。

## 主题色（自由定制）

模板默认使用 Icarus 品牌色 `#2F2FE4` 作为节标题主色（竖条、横线、标题文字）。如果想换成自己的简历主题色：

1. 到 <https://colorhunt.co/> 找一组 4 色配色；
2. 选其中 1 个作为主色，1 个深色作为正文；
3. 把模板里这一行替换掉：

```latex
\definecolor{sectionblue}{HTML}{2F2FE4}
```

- `2F2FE4` 换成你选的 HEX 值（去掉 `#`）；
- 中文 / 英文 / A / P 四份模板同步替换；
- 建议只换主色一项，其余颜色（背景、链接、灰阶）保持默认，避免版面过于花哨。

如果改完色后觉得节标题不够突出，先只调主色饱和度，不要同时改三处（标题、横线、竖条）颜色。

# 编译与校验

## 编译

```bash
cd <模板或 tex 所在目录>
latexmk -xelatex -interaction=nonstopmode -halt-on-error 简历.tex
```

字体/照片路径均为相对路径：模板 tex 放在与 `tabler-icons/`、`中文简历照片/` 同级的位置即可编译。

## 校验命令

```bash
# 页数
pdfinfo 简历.pdf | rg Pages

# 字体是否嵌入（应看到 Source Han Sans CN / Helvetica / tabler-icons）
pdffonts 简历.pdf

# 文字是否可提取（中文应正常输出，而不是乱码/替换符）
pdftotext 简历.pdf - | head

# 页面底部余量（A4，1.27cm 上下边距时可用高度约 805.7pt）
pdftotext -bbox 简历.pdf - | rg -o 'yMax="[0-9.]+"'
```

中文用思源黑体 CN 时，必须保留 `\XeTeXgenerateactualtext=1`，否则 PDF 文字层会变成替换符，HR 系统抓不到。

## 内容一致性核对

用归一化文本做逐行/逐要点比对：去掉空格与标点后，MD 的每条要点都应出现在 PDF 提取文本中（英文注意连字符换行、`ﬁ` 连字、引号变体；中文注意数字/单位写法）。发现 MD 有内容但 PDF 缺失，先查映射是否漏行，再查字体/提取问题。

## Tabler Icons 码点

| 用途 | 图标 | Unicode |
|---|---|---|
| 电话 | phone | `EB09` |
| 邮箱 | mail | `EAE5` |
| 微信 | brand-wechat | `F5F3` |
| 领英 | brand-linkedin | `EC8C` |
| 个人网站 | briefcase | `EA46` |

用法：

```latex
\newfontfamily{\tablerfont}[Path=../tabler-icons/]{tabler-icons.ttf}
\newcommand{\tiPhone}{{\tablerfont\symbol{"EB09}}}
```

路径按 tex 实际位置调整（`_LaTeX源文件/` 下为 `../../Latex模板/tabler-icons/`）。
